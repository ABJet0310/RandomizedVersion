THE RULES

It really is random.

  1. Events use different random formats. The catalogue includes voting, turn-based, round-based, sports, and playing-card events, including Letter Values, Catching, a survival simulation, and randomized sports marks.
  2. Final rank is decided before points are awarded. Event results break ties when possible; unresolved ties get a random extra round. Every rank then receives a distinct point award.
  3. The first two events are safe. Nobody goes home until after Event 3.
  4. After Event 3, the lowest total scorers are eliminated. The cut adjusts to bring the field down to three finalists by Event 20.
  5. The finale decides the season. Choose one event or a three-part finale. The player with the most total points wins.
  6. Standard RV points grow with the event number. The single-finale top award rises to 1,200 at Event 20. For a three-part finale, each part awards one-third of the Event 20 rank schedule (400 for first place). Hosts may instead enter a custom rank table separately for every event.
  7. Playoffs run for 20 events with the full cast competing throughout. Ranks 1–2 earn 40 and 35 points; ranks 3–35 descend by one point per rank, and rank 36 onward earns 1. The first 10 events rank by event wins, then points. Events 10, 13, 16, and 19 qualify the top 16, 12, 8, and 4 for point resets; other participants keep competing and earning points. Later checkpoints narrow the previously qualified group, with prior leaderboard position breaking qualification ties.
  8. Playoff points reset at each qualification checkpoint. Qualifiers reset to 1,000 / 2,000 / 3,000 points plus accumulated stage points after Events 10 / 13 / 16. Event 19 qualifiers reset to 4,000 without stage points. Each event has two random stage winners; a winner may win both stages, and stage points count only when added at a reset.
  9. Choose each season event when it is ready to start. Select a catalogue format and use its standard rules or customize its settings. Standard RV seasons may also use a reusable, host-named rank-to-points table.
  10. Eurovision adapts to field size. Up to 30 entrants compete in one final; larger fields use two semi-finals, with the top 13 from each qualifying. Ties compare total points, then 12s, 10s, and so on to 1.
  11. Country Choosing uses recognized countries in the current country dataset. The list is not capped at 197; statistics use the latest World Bank data available.
  12. Letter Values uses a bundled CMUdict word list. The Oxford Dictionary is not bundled; the included open-license word list and license notice are provided in the project.
  13. Hosts choose each username, unique color name, and background. Common CSS color names fill in their standard hex value; hosts may customize the hex or choose a gradient or image.
